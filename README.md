# STM32 Remote Control

Приложение для удалённого управления и мониторинга STM32 устройства через веб-интерфейс.

## 📋 Описание

**STM32 Remote Control** — это полнофункциональное приложение для удалённого управления и мониторинга STM32 микроконтроллерачерез Интернет и локальную сеть.

Приложение включает:

- **Веб-интерфейс** для управления и мониторинга в реальном времени
- **Управление реле** (включение/выключение) с подтверждением статуса
- **Мониторинг напряжения** питания устройства
- **Статус соединения** с устройством и сервером
- **Логирование** всех операций и команд
- **Поддержка mock-устройства** для тестирования без железа
- **Удалённое подключение** через ngrok для доступа из Интернета
- **Гибкая архитектура** для работы как локально, так и удалённо

## 🏗️ Архитектура

### Локальное подключение (LAN)
```
Frontend (React + Vite + Tailwind CSS)
         ↕️ WebSocket (порт 8080)
Backend (Node.js)
         ↕️ TCP (порт 8081)
STM32 Device (через DT-06 модуль)
```

### Удалённое подключение (через Интернет с ngrok)
```
Frontend (React + Vite + Tailwind CSS)
         ↕️ WebSocket (локально)
Backend (Node.js)
         ↕️ TCP
         ↓
ngrok (TCP tunnel)
    ↕️ ngrok public URL
    ↓
STM32 Device (в удалённой локации, через DT-06 модуль)
```

ngrok создаёт защищённый туннель для безопасного подключения удалённого устройства к вашему Backend серверу.

### Компоненты

**Backend (`backend/`)**
- `server.js` — основной сервер с поддержкой WebSocket (фронтенд) и TCP (STM32)
- `mock-device.js` — имитация STM32 устройства для разработки и тестирования

**Frontend (`frontend/`)**
- React компонент `App.jsx` с элементами управления и мониторинга
- Tailwind CSS для стилизации
- Vite для сборки и разработки

## 🚀 Быстрый старт

## 🎮 Запуск локально

### Вариант 1: Запуск с Mock-устройством (рекомендуется для тестирования)

Этот режим запускает сервер вместе с имитацией STM32 устройства — отлично подходит для разработки без физического устройства.

**Из папки `backend/`:**
```bash
npm run dev
```

Это запустит одновременно:
- Backend сервер (WebSocket на порту 8080, TCP на порту 8081)
- Mock-устройство (имитирует STM32)

**Из папки `frontend/`** (открыть в новом терминале):
```bash
npm run dev
```

Откройте браузер и перейдите по адресу: **http://localhost:5173**

### Вариант 2: Запуск только Backend сервера

Используйте, если у вас есть реальное STM32 устройство, подключённое к компьютеру:

**Из папки `backend/`:**
```bash
npm start
```

Или запустите сервер напрямую:
```bash
node server.js
```

Оба команды запустят Backend сервер:
- WebSocket сервер на порту 8080 (для фронтенда)
- TCP сервер на порту 8081 (для STM32 устройства)

Сервер запустится и будет ждать подключения STM32 устройства на TCP порту 8081.

**Из папки `frontend/`** (открыть в новом терминале):
```bash
npm run dev
```

## 🕹️ Использование

### Основной интерфейс

1. **Статус соединения** — показывает состояние подключения к серверу (зелёный — подключено)
2. **Статус устройства** — показывает, подключено ли STM32 устройство (зелёный — устройство онлайн)
3. **Управление реле**
   - Кнопка **ON** — включить реле
   - Кнопка **OFF** — выключить реле
4. **Телеметрия** — отображает текущее напряжение питания устройства
5. **Логи** — история всех операций и сообщений в реальном времени

### Сценарии работы

**С Mock-устройством:**
- Всё работает на локальной машине
- Управляющие команды отправляются в mock-устройство
- Mock-устройство имитирует изменение состояния и отправляет обратно телеметрию

**С реальным STM32:**
- STM32 подключается к Backend серверу через TCP (DT-06 модуль)
- Frontend отправляет команды через WebSocket → Backend → TCP → STM32
- STM32 отправляет телеметрию обратно: TCP → Backend → WebSocket → Frontend

## 📡 API и Порты

| Компонент | Порт | Тип | Описание |
|-----------|------|-----|---------|
| Frontend | 5173 | HTTP | Веб-интерфейс (Vite dev server) |
| Backend WebSocket | 8080 | WS | Коммуникация с фронтенд-клиентами |
| Backend TCP | 8081 | TCP | Коммуникация с STM32 устройством |

### Переменные окружения

Вы можете переопределить порты через переменные окружения:

```bash
# Backend
WS_PORT=9000 TCP_PORT=9001 npm start

# Frontend
VITE_WS_URL=ws://192.168.1.100:8080 npm run dev
```

## 🌐 Удалённое подключение STM32 через DT-06 и ngrok

Если STM32 устройство находится удалённо (не в локальной сети), можно использовать **ngrok** для проксирования TCP портов.

### Установка ngrok

1. Скачайте ngrok с сайта: https://ngrok.com/download
2. Распакуйте архив в удобную папку
3. Зарегистрируйтесь на ngrok.com и получите токен авторизации
4. Авторизуйте ngrok:
   ```bash
   ngrok config add-authtoken <ВАШ_ТОКЕН>
   ```

### Запуск Backend с ngrok

1. **Запустите Backend сервер:**
   ```bash
   cd backend
   node server.js
   ```
   Backend будет слушать на порту 8081 для STM32 устройства.

2. **В новом терминале запустите ngrok для проксирования TCP порта 8081:**
   ```bash
   ngrok tcp 8081
   ```

3. **Результат в консоли ngrok:**
   ```
   Forwarding                    tcp://0.tcp.ngrok.io:12345 -> localhost:8081
   ```
   
   Запомните адрес: **0.tcp.ngrok.io:12345** (ваш номер порта будет другой)

4. **Получите IP адрес ngrok адреса** (так как STM32 работает только с IP адресами, не с доменными именами):
   
   Откройте командную строку / терминал и выполните команду ping:
   ```bash
   ping 0.tcp.ngrok.io
   ```
   
   Результат (пример):
   ```
   Pinging 0.tcp.ngrok.io [34.212.45.67] with 32 bytes of data:
   Reply from 34.212.45.67: bytes=32 time=25ms TTL=52
   ```
   
   Запомните полученный **IP адрес:** `34.212.45.67` (ваш адрес будет другим)

### Настройка DT-06 модуля

В интерфейсе конфигурации DT-06 модуля (через веб-браузер или приложение) используйте **IP адрес** (а не доменное имя):

- **Сервер:** `34.212.45.67` (IP адрес из результата ping, полученный на предыдущем шаге)
- **Порт:** `12345` (замените на ваш порт из ngrok)
- **Тип подключения:** TCP Client
- **Протокол:** JSON

Пример конфигурации:
```
┌─ DT-06 Configuration ─┐
│ Mode: TCP Client      │
│ Host: 34.212.45.67    │
│ Port: 12345           │
│ Protocol: JSON        │
└───────────────────────┘
```

### Важно

⚠️ **Порт и IP адрес ngrok меняются при перезапуске**, поэтому:
- Если нужны постоянные адрес и порт, используйте **ngrok Pro** (платный)
- После каждого перезапуска ngrok выполните ping чтобы получить новый IP
- Обновляйте IP адрес в конфигурации DT-06

### Альтернатива: Локальный запуск на одной машине

Если всё на одной машине:
```bash
# Backend
node server.js              # Слушает на localhost:8081

# DT-06 конфигурация
Host: 127.0.0.1
Port: 8081
```

### Просмотр логов

- **Backend**: логи выводятся в консоль
- **Frontend**: откройте DevTools (F12) → Console


## 🔌 Подключение реального STM32 устройства (удалённое)

### Предусловия

- **STM32 устройство** с модулем DT-06 (WiFi модуль)
- **ngrok** установлен и авторизован (см. инструкции в разделе "Удалённое подключение STM32 через DT-06 и ngrok")
- **Backend сервер** запущен на вашей машине/сервере

### Пошаговая инструкция

#### Шаг 1: Запустите Backend сервер

На машине/сервере, где будет запущен Backend:

```bash
cd backend
node server.js
```

Вы должны увидеть в консоли:
```
WebSocket server (Frontend) started on port 8080
TCP server (STM32/DT-06) started on port 8081
```

#### Шаг 2: Запустите ngrok туннель

В новом терминале запустите ngrok для проксирования TCP порта 8081:

```bash
.\ngrok tcp 8081
```

Сохраните выведённый адрес (пример):
```
Forwarding    tcp://3.tcp.ngrok.io:15432 -> localhost:8081
```

#### Шаг 3: Получите IP адрес ngrok

**⚠️ Важно: STM32 не может работать с доменными именами (URL), только с IP адресами!**

Откройте командную строку и выполните ping:
```bash
ping 3.tcp.ngrok.io
```

Вы получите результат (пример):
```
Pinging 3.tcp.ngrok.io [34.212.45.67] with 32 bytes of data:
Reply from 34.212.45.67: bytes=32 time=15ms TTL=52
```

**Скопируйте IP адрес:** `34.212.45.67` (ваш адрес будет другим)

#### Шаг 4: Настройте DT-06 модуль

На странице конфигурации DT-06 (через веб-интерфейс или приложение) используйте полученный **IP адрес**:

| Поле | Значение | Пример |
|------|----------|--------|
| **Mode / Режим** | TCP Client | TCP Client |
| **Server / Сервер** | IP адрес из ping | 34.212.45.67 |
| **Port / Порт** | ngrok порт | 15432 |
| **Protocol / Протокол** | JSON | JSON |
| **Auto Connect** | Включить | Enable ✓ |

**Пример конфигурации DT-06:**
```
┌────── DT-06 Configuration ──────┐
│ Mode:           TCP Client      │
│ Server:         34.212.45.67    │
│ Port:           15432           │
│ Protocol:       JSON            │
│ Auto Connect:   Enable          │
└─────────────────────────────────┘
```

#### Шаг 5: Запустите Frontend

На вашей машине (где вы работаете):

```bash
cd frontend
npm run dev
```

Откройте браузер: **http://localhost:5173**

#### Шаг 6: Проверьте подключение

- **Статус Backend:** должен быть зелёный (WebSocket подключен)
- **Статус STM32:** должен быть зелёный (устройство онлайн через ngrok туннель)
- **Логи:** вы должны увидеть логи подключения в интерфейсе

### 📊 Пример работы

1. STM32 с DT-06 подключается к IP адресу ngrok: `34.212.45.67:15432` (полученный через ping)
2. ngrok перенаправляет соединение на ваш Backend: `localhost:8081`
3. Backend принимает соединение от STM32
4. Frontend получает информацию через WebSocket: `localhost:8080`
5. Вы видите статус устройства в реальном времени
6. Команды отправляются: Frontend → WebSocket → Backend → ngrok → STM32

### ⚠️ Важные замечания

- **Порт и IP адрес ngrok меняются при перезапуске** — обновите конфигурацию DT-06
  - Выполните ping командой: `ping <ngrok-адрес>` чтобы получить новый IP
  - Обновите IP адрес в настройках DT-06 модуля
- Для **постоянного URL и IP** используйте **ngrok Pro** (платная подписка)
- **ngrok бесплатный** предоставляет ~40 часов в месяц
- Убедитесь, что **Backend доступен в Интернете** (или запустите на облачном сервере)

### 🔒 Безопасность

- ngrok используется только для туннелирования TCP, данные защищены
- Рекомендуется использовать ngrok Pro для дополнительных функций безопасности
- Не передавайте ngrok URL третьим лицам

### Локальное подключение (без ngrok)

Если STM32 находится в **локальной сети** с Backend сервером:

1. Запустите Backend: `node server.js`
2. В конфигурации DT-06 используйте:
   - **Server:** `192.168.1.100` (IP адрес машины с Backend)
   - **Port:** `8081`
